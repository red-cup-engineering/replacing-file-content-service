## Verified acceptance cases

Specification basis. Preview and apply atomic literal text replacements in one selected file.

| Case | Check | Behavior |
| --- | --- | --- |
| ` REPLACE-CONTENT-REFUSAL ` | source refusal | A replacement refuses when its expected match count differs from the observed count. |
| ` REPLACE-CONTENT-QUICKSTART ` | consumer example | An installed caller previews the selected text edit and explicitly applies it. |
